Real Hoboken needs a Google key

The real city streams from Google's Photorealistic 3D Tiles (the Google Earth 3D scan). Paste a Google Maps Platform API key with the Map Tiles API turned on. How to get one.
The key is kept only in this browser. Google bills the key's owner for tile requests.
Heads up: the Claude viewer blocks outside downloads, so the Google city won't load in here. Play the real-city mode at itemnautsoft.github.io/Soft.
